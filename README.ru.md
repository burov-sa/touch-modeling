# Локализация точки касания с помощью Keras DNN

Прототип синтетической локализации точки касания: генерация показаний сенсорной сетки 3×4, обучение небольшой Keras DNN и предсказание непрерывных координат касания `(x, y)`.

## Обзор

Проект демонстрирует пайплайн регрессии для оценки координат точки касания по 12 значениям сенсоров, расположенным в виде сетки 3×4.

Пайплайн состоит из трёх Jupyter-ноутбуков:

1. `1.GenLearnData.ipynb` — генерирует синтетические train/test датасеты.
2. `2.Learning and test.ipynb` — обучает DNN и оценивает качество регрессии.
3. `3.Test.ipynb` — загружает сохранённую архитектуру модели и выполняет предсказание.

Модель предсказывает два непрерывных значения: горизонтальную координату `x` и вертикальную координату `y`.

## Генерация данных

Функция `touch_generate()` создаёт синтетическую сетку 3×4 с базовыми значениями около `fNorm = 128` и гауссовым шумом. Случайная точка касания размещается в центральной области, после чего значения ближайших ячеек изменяются в зависимости от евклидова расстояния до точки касания и случайного радиуса.

Каждый пример содержит:

- `value`: развёрнутые 12 показаний сенсоров из сетки 3×4;
- `xy`: целевые координаты касания `[x, y]`.

Параметры генерации по умолчанию:

- размер сетки: 3 строки × 4 столбца = 12 признаков;
- базовое значение: `fNorm = 128`;
- уровень шума: `eSilence = 3`;
- радиус касания: случайный в `[0.2, 1.0]`;
- координаты: примерно в диапазоне `[2.0, 3.0)`;
- размер train: 15 000 примеров;
- размер test: 5 000 примеров.

Сгенерированные датасеты сохраняются как:

```text
df_train.pickle
df_test.pickle
```

## Модель

DNN описана в `2.Learning and test.ipynb`:

```python
model1 = Sequential([
    Dense(14, kernel_initializer='normal', activation='relu', input_shape=(12,), name="hidden_1"),
    Dense(2, kernel_initializer='normal', name="output")
])
model1.compile(optimizer='rmsprop', loss='mse', metrics=['mae'])
model1.fit(X, Y, batch_size=3, epochs=20)
```

Архитектура:

| Слой | Тип | Нейронов | Активация |
|---|---|---:|---|
| hidden_1 | Dense | 14 | ReLU |
| output | Dense | 2 | Linear |

Параметры обучения:

- оптимизатор: RMSprop;
- функция потерь: MSE;
- метрика: MAE;
- размер батча: 3;
- эпох: 20.

## Результаты

На синтетическом тестовом наборе ноутбук показывает:

```text
r2_score = 0.9071975975509872
```

Также строится гистограмма евклидовых ошибок между предсказанными и истинными координатами `(x, y)`.

Результаты получены на синтетических данных и могут меняться между запусками, так как фиксированный random seed не используется.

## Использование

### 1. Генерация датасетов

Откройте и запустите:

```text
1.GenLearnData.ipynb
```

Будут созданы `df_train.pickle` и `df_test.pickle`.

### 2. Обучение и оценка модели

Откройте и запустите:

```text
2.Learning and test.ipynb
```

Ноутбук обучает DNN, вычисляет `r2_score`, строит гистограмму ошибок и сохраняет архитектуру модели в `model1.json`.

### 3. Инференс

Откройте и запустите:

```text
3.Test.ipynb
```

Важно: `model1.json` содержит только архитектуру модели, но не обученные веса. Чтобы использовать обученную модель, сохраните веса после обучения и загрузите их перед предсказанием:

```python
# После обучения
model1.save_weights("model1.h5")

# Перед предсказанием
model1.load_weights("model1.h5")
```

## Ограничения и замечания

- Данные полностью синтетические и не описывают реальный сенсор касаний.
- Фиксированный random seed не используется, поэтому результаты не полностью воспроизводимы.
- Модель предсказывает координаты только в центральной области сетки, примерно `[2.0, 3.0)` по обеим осям.
- `model1.json` хранит только архитектуру. Обученные веса в текущих ноутбуках не сохраняются.
- Ноутбуки используют `DataFrame.append`, который устарел в современных версиях pandas. Для pandas 2.0+ замените его на `pd.concat` или накопление в списке.
- В `3.Test.ipynb` есть посторонний код, связанный с `forest1` / `forest2`; он не относится к основному пайплайну.
