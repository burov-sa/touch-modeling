# Локализация точки касания с помощью Keras DNN

Прототип синтетической локализации точки касания: генерация показаний сенсорной сетки 3×4, обучение небольшой Keras DNN и предсказание непрерывных координат касания `(x, y)`.

## Обзор

Проект демонстрирует пайплайн регрессии для оценки координат точки касания по 12 значениям сенсоров, arranged as a 3×4 grid.

Пайплайн состоит из трёх Jupyter-ноутбуков:

1. `1.GenLearnData.ipynb` — генерирует синтетические train/test датасеты.
2. `2.Learning and test.ipynb` — обучает DNN и оценивает качество регрессии.
3. `3.Test.ipynb` — загружает сохранённую архитектуру модели и выполняет предсказание.

Модель предсказывает два непрерывных значения: горизонтальную координату `x` и вертикальную координату `y`.

## Генерация данных

Функция `touch_generate()` создаёт синтетическую сетку 3×4 с базовыми значениями около `fNorm = 128` и гауссовым шумом. Случайная точка касания размещается в центральной области, после чего значения ближайших ячеек изменяются в зависимости от евклидова расстояния до точки касания и случайного радиуса.

Каждый пример содержит:

- `value`: flattened 12 sensor readings from the 3×4 grid;
- `xy`: target touch coordinates `[x, y]`.

Параметры генерации по умолчанию:

- размер сетки: 3 строки × 4 столбца = 12 признаков;
- базовое значение: `fNorm = 128`;
- уровень шума: `eSilence = 3`;
- радиус касания: случайный в `[0.2, 1.0]`;
- координаты: примерно в диапазоне `[2.0, 3.0)`;
- размер train: 15 000 примеров;
- размер test: 5 000 примеров.
