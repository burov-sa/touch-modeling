# Touch Point Localization with Keras DNN

Synthetic touch-point localization prototype: generate readings from a 3×4 sensor grid, train a small Keras DNN, and predict continuous touch coordinates `(x, y)`.

## Overview

This project demonstrates a regression pipeline for estimating the coordinates of a touch point from 12 sensor values arranged as a 3×4 grid.

The pipeline consists of three Jupyter notebooks:

1. `1.GenLearnData.ipynb` — generates synthetic train/test datasets.
2. `2.Learning and test.ipynb` — trains a DNN and evaluates regression quality.
3. `3.Test.ipynb` — loads the saved model architecture and runs inference.

The model predicts two continuous values: horizontal coordinate `x` and vertical coordinate `y`.

## Data Generation

The function `touch_generate()` creates a synthetic 3×4 grid of baseline values around `fNorm = 128` with Gaussian noise. A random touch point is placed inside the central region, and nearby grid cells are modified depending on the Euclidean distance from the touch point and a random touch radius.

Each sample contains:

- `value`: flattened 12 sensor readings from the 3×4 grid;
- `xy`: target touch coordinates `[x, y]`.

Default generation parameters:

- grid size: 3 rows × 4 columns = 12 features;
- baseline value: `fNorm = 128`;
- noise level: `eSilence = 3`;
- touch radius: random in `[0.2, 1.0]`;
- coordinates: approximately in the range `[2.0, 3.0)`;
- train size: 15 000 samples;
- test size: 5 000 samples.

Generated datasets are saved as:

```text
df_train.pickle
df_test.pickle
```

## Model

The DNN is defined in `2.Learning and test.ipynb`:

```python
model1 = Sequential([
    Dense(14, kernel_initializer='normal', activation='relu', input_shape=(12,), name="hidden_1"),
    Dense(2, kernel_initializer='normal', name="output")
])
model1.compile(optimizer='rmsprop', loss='mse', metrics=['mae'])
model1.fit(X, Y, batch_size=3, epochs=20)
```

Architecture summary:

| Layer | Type | Units | Activation |
|---|---|---:|---|
| hidden_1 | Dense | 14 | ReLU |
| output | Dense | 2 | Linear |

Training configuration:

- optimizer: RMSprop;
- loss: MSE;
- metric: MAE;
- batch size: 3;
- epochs: 20.

## Results

On the synthetic test set, the notebook reports:

```text
r2_score = 0.9071975975509872
```

The notebook also plots a histogram of Euclidean coordinate errors between predicted and true `(x, y)` values.

These results are obtained on synthetic data and may vary between runs because no fixed random seed is used.

## Usage

### 1. Generate datasets

Open and run:

```text
1.GenLearnData.ipynb
```

This creates `df_train.pickle` and `df_test.pickle`.

### 2. Train and evaluate the model

Open and run:

```text
2.Learning and test.ipynb
```

The notebook trains the DNN, evaluates `r2_score`, plots the error histogram, and saves the model architecture to `model1.json`.

### 3. Run inference

Open and run:

```text
3.Test.ipynb
```

Note: `model1.json` contains only the model architecture, not trained weights. To reuse the trained model, save weights after training and load them before prediction:

```python
# After training
model1.save_weights("model1.h5")

# Before prediction
model1.load_weights("model1.h5")
```

## Limitations and Notes

- The data is fully synthetic and does not represent a real touch sensor.
- No fixed random seed is used, so results are not fully reproducible.
- The model predicts coordinates only in the central region of the grid, approximately `[2.0, 3.0)` for both axes.
- `model1.json` stores only the architecture. Trained weights are not saved in the current notebooks.
- The notebooks use `DataFrame.append`, which is deprecated in modern pandas versions. For pandas 2.0+, replace it with `pd.concat` or list accumulation.
- `3.Test.ipynb` contains unrelated leftover code related to `forest1` / `forest2`; it is not part of the main pipeline.
